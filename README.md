# Bot_API

Bot_API — это простой HTTP API-сервер для управления Telegram-ботом через Telegram Bot API.

Проект написан на Node.js и использует:

- Express
- dotenv
- node-telegram-bot-api

Сервер позволяет отправлять сообщения, фото, получать информацию о боте и задавать команды через HTTP-запросы.

## Возможности

- Проверка работы сервера
- Получение информации о Telegram-боте
- Отправка сообщений в Telegram
- Отправка фото
- Установка команд бота
- Защита API через `x-api-key`
- Работа локально и на Render
