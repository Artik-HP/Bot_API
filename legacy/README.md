# Архив Bot_API

`gateway.cjs` — исходная точка входа шлюза из коммита `4fad32f`, сохранённая перед созданием PulseDesk. Она не импортируется новым приложением, не запускается npm-командами и не является поддерживаемым режимом PulseDesk.

Её прежние зависимости и конфигурация доступны в Git-истории. В старом шлюзе обнаружены ограничения доступа, обработки webhook и надёжности; подробности — в `docs/AUDIT_2026-11-03.md`. Запускать архив с прежними секретами без исправлений нельзя. Секреты и локальные данные сюда не скопированы.
